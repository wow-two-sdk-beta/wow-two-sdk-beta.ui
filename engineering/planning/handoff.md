## Adoption sweep + `share` (2026-07-13, 4 parallel agents)

- **`foundation/share`** — Web Share + clipboard fallback. `canShare` · `share` → `shared`/`dismissed`/`unsupported`/`failed` · `shareOrCopy` (falls back on `unsupported` ONLY — a user who cancelled must not get a surprise clipboard write) · `useShare`. Never throws. Reuses `errors.isAbortError` for dismissal. `useClipboard` could NOT be delegated to (it's a hook, and its `copy` resolves on both success and failure), so the fallback calls `navigator.clipboard.writeText` directly — reasoning recorded in `ShareOrCopy.ts`. 34 tests.
- **`CommandPalette` → `useHotkeys`** — hand-rolled `document` keydown deleted (net −8). Bound as `['mod+K','ctrl+K','meta+K']`, NOT bare `mod+K`: the old predicate was `(metaKey || ctrlKey)`, i.e. both accepted on every platform, and bare `mod+K` is meta-only on macOS (it broke the existing `{Control>}k` story). **Behavior delta, accepted**: modifier matching is now exact, so `⌘⇧K`/`⌃⌥K` no longer open the palette (the old check ignored shift/alt). +2 play stories, incl. one proving ⌃K still opens while a text field is focused (mod-combos survive `ignoreInputs`).
- **`FileUpload` → `foundation/files`** — private `matchesAccept` + duplicated dragenter token-parse deleted (net −20). **Intentional bug fix**: the dragenter check hard-returned `false` for extension tokens, so dragging a `.png` onto an `accept=".png"` zone painted REJECT even though the drop succeeded. Now fail-open (`extensionTokens: 'allow'`); `handleDrop` still re-checks authoritatively. No test asserted the old behavior.
- **`http`/`query` → `foundation/errors`** — 4 sites: `CreateApiClient`'s private `instanceof DOMException` `isAbortError` (now cross-realm + plain-shape safe), its network-error message, `CreateQueryClient`'s abort branch, `ToApiError`'s Error/string branches. **One non-superset delta**: an error with a blank or `'[object Object]'` message now yields the fallback string instead of propagating `''` into `ApiError.message`.
- **Not adopted, with reasons**: `ChatComposer` (a `useHotkeys` native listener fires before React's synthetic `onKeyDown`, breaking the `textareaProps.onKeyDown` `defaultPrevented` opt-out) · `FilePicker` (no accept/size logic — `accept` goes straight to the native input) · `Envelope.toError` / `ApiError` message precedence / `FieldErrors` narrowing (all API-specific, deliberately narrower than the generic vector).

## Gotchas (cost real time this session)

- **`pnpm test` (all 3 projects at once) saturates this machine** — `unit` + `browser` + `storybook` each drive workers, and past ~2.1k tests three browser tests (`FocusScope` restore-focus · `DismissableLayer` outside-pointer · `RovingFocusGroup` Tab) hit 15–20 s `locator.click` timeouts. Symptom is a *wedged iframe* (the locator never resolves; even `locator.screenshot` times out), not an assertion failure or a DOM overlay. **Verify per-project** (`--project unit`, `--project browser`) — both are fully green. Fix, when someone owns it: cap browser-project parallelism or raise its `testTimeout`; not changed here because it is shared config affecting every lane.
- **Parallel agents must not share config files.** Building 4 vectors concurrently works only if each agent owns a disjoint `src/` slice and the orchestrator makes every `tsup.config.ts` / `package.json` / `vitest.config.ts` / `eslint.config.js` / `lib-source-alias.mjs` edit. A new **top-level** subpath (`analytics`, `flags`) additionally needs an `eslint.config.js` `boundaries/elements` entry + an `element-types` rule, or `boundaries/no-unknown` fails the lint.
- **`git add -A` sweeps in Vitest failure screenshots** (`.vitest-attachments/*.png`, `**/__screenshots__/`) left by any test that failed during the session. Neither path is gitignored, and 16 such PNGs are already committed. Stage explicitly, or check `git status` before staging.

- **`guard-git.py` hook BLOCKS agent `git commit`/`git push`** — it activated mid-session. Agents **stage** (`git add`) + hand the human a one-liner `feat: …` message (no description / co-author / Claude mention); the human commits + **pushes**. NEVER push.
- **Verify current state before "building" a vector** — z-index, motion tokens, and Toaster pause/actions/`Announce` were **already built**. The SDK is more mature than the vector list implies; grep/read first, then fill the real gap.
- **Shell is zsh**: `$var` does NOT word-split (use `${(f)var}` newline-split / `${=var}` word-split); `$PIPESTATUS` → `$pipestatus[1]`; a `cmd | tail` **masks the exit code** — capture `$?` without the pipe, or the failure hides.
- **cold-cache vite flake** (`Cannot read properties of null (reading 'useId')`) — transient dep-optimization race after a structural change; re-run (`pnpm test || pnpm test`). Documented in `../architecture/testing.md`.
- `CLAUDE.md` is at the **repo root**, not the package dir. `@src/*` alias resolves tests → source. Vitest path filters are substring matches.
